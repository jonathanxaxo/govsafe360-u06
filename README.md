# GOVSAFE 360 — construção assistida (M6)

Este é o projeto didático construído progressivamente nos marcos autorizados. A versão atual possui dashboard, motor de governança, cadastro local, busca, filtros, revisão humana simulada, auditoria, exportações e testes de qualidade.

Para validar a versão atual:

```powershell
npm run quality
```

Abra `index.html` diretamente ou use o servidor local já previsto pelo curso. Consulte `docs/CRITERIOS_ACEITE.md`, `docs/EVIDENCIAS_M5.md` e `docs/HISTORICO_GIT_M6.md`.

O projeto usa somente dados fictícios e não é um sistema institucional homologado. Não há integração com sistemas oficiais, autenticação institucional ou banco compartilhado.
